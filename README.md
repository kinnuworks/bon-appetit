# Bon·Appétit

Swiss supermarket receipts to a household food picture, on your own computer, with Apertus v1.5.

Hack Apertus 2026, Track 2B. The project lives in [`track_2b/`](track_2b/): start with its [README](track_2b/README.md). Judges run `make run` from this folder.

Website and live demo: https://kinnuworks.github.io/bon-appetit/
